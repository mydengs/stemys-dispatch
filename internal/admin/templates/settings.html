防采集伪装（入口对爬虫/探测请求显示中性公告页）

爬虫与厂商安全探测（内置常见爬虫规则 + 浏览器 prefetch 预取 + 下面自定义关键字）访问入口时， 直接看到中性「公告页」：不出验证弹窗、不出 302，采集不到分发行为和落地域名。
建议做法：先在「点击明细」观察可疑流量（短时间高频、UA 像浏览器但从不完成验证），把其 UA 特征加进下面列表，再保存。

内置规则已覆盖常见搜索引擎爬虫与无头工具；厂商安全爬虫 UA 多变，请按点击明细里的实际 UA 补充。
厂商云侧检测来自机房 IP，真实用户来自家宽/4G——IP 比 UA 可靠。可粘贴腾讯云 AS(AS4366/AS58941 等)公告的段，或按点击明细里可疑 IP 归属补充。

网络类型闸门（判断访客是否运营商真实接入）

出口 IP 命中「运营商白名单 CIDR」（电信 AS4134 / 联通 AS4837、AS9929 / 移动 AS9808 / 鹏博士 / 长城宽带等的公告前缀，含 IPv6）→ 记为运营商网络≈真实家宽/4G/5G； 命中上方机房黑名单 → 黑名单（优先于白名单判定）；都不命中 → 白名单外（云机房/政企专线/教育网/VPN 出口等）。
局限说明：同一运营商池内「4G/5G 基站出口」与「家宽」无法用 IP 精确区分；挂在运营商线路上的 IDC 也会被算进白名单——由机房黑名单兜底。
新域名投放套路：先用「观察」模式跑几天，「点击明细」网络类型列里「白名单外」且明显是真人（能通过验证、有落地点击）的网段补进白名单，确认无误后再切「严格」。

已预置四大运营商+CN2+主流二级宽带的 IRR 公告前缀（聚合后约 1740 条，含 2408:8000::/20、2409:8000::/21、240e::/20 等 IPv6 大段）。广电/教育网/企业专线默认不在表内——按点击明细补充即可。

地域兜底（无国家注头时的访客国家）

访客国家只来自请求头（CF-IPCountry / X-Country-Code 等，由 Cloudflare 或 nginx geoip 注入）——本程序不查 IP。没接 CDN 也没配 geoip 时，所有人都会被当成 ZZ，此时任何设了国家定向的落地页会对全体访客静默 404「暂无可用的落地页」。国内投放的裸 nginx/宝塔部署在这里填 CN 即可兜底；已注头的部署留空，行为不变。保存立即生效，重启自动加载。
